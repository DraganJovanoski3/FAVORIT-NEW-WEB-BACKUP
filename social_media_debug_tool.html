🐛 Common Issues & Solutions

❌ Issue: "Missing Properties - fb:app_id"

Status: ✅ FIXED

Facebook App ID has been commented out in both product and blog generators.

❌ Issue: "Redirects to homepage instead of product/blog"

Status: ⚠️ CHECKING

This happens when .htaccess routing doesn't work properly. Check:

  • Static HTML files exist in root directory
  • .htaccess file is uploaded correctly
  • Bot detection is working

❌ Issue: "Wrong image type"

Status: ✅ FIXED

Image type meta tags now match actual file extensions (PNG for products, JPEG for blogs).

❌ Issue: "Generic descriptions"

Status: ✅ FIXED

Blog descriptions now use meaningful content from first section instead of generic excerpt.

❌ Issue: "Cyrillic URLs not working"

Status: ✅ FIXED

Blog URLs now use Latin Macedonian characters for better compatibility.
